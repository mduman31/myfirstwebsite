## 📂 Project Source Code

### 1. HTML File (`index.html`)
This file controls the layout and structural elements of the webpage:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>This is my website</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
   <h1>Hello World</h1>
   <p>my name is MaryAnn Duman.</p>
   <h2>Welcome to my website</h2>
</body>
</html>
```

### 2. Stylesheet (`styles.css`)
This file manages the visual design, colors, and layout aesthetics:

```css
body {
    background-color: #4db6ac; /* Mermaid teal/aqua color */
    color: #ffffff; /* White text for contrast */
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; /* Cute, modern font */
    text-align: center; /* Centers all text, including headings */
    padding-top: 50px;
}

h1, h2 {
    color: #e0f2f1; /* Light, soft mint color for headings */
    text-shadow: 1px 1px 2px rgba(0, 0, 0, 0.1); /* Adds a subtle depth */
}
```
